How to Reproduce Data Cleaning:

1.) Download WhatnotDataRefined1023.csv, this is our uncleaned dataset with most recent attributes.

2.) Copy the code in pyCodeCleanScript, this is our cleaning script using Pandas.

3.) Open up a Google Colab.

4.) Paste the code into your opened Colab file.

5.) Upload WhatnotDataRefined1023.csv into the local files of your Colab.

6.) Run the code and a new cleaned dataset will be download once the code finishes.
